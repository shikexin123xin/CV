# 交互式个人简历网页

这是一个简洁、具有设计感并带交互效果的个人简历网页示例，包含：

- 个人信息（首页卡片）
- 技能特长（技能进度条）
- 工作经历（时间线）
- 项目展示（卡片式）
- 联系方式（示例表单）

主要特性：

- 使用 CSS 变量与渐变配色，视觉简洁大方
- 使用 IntersectionObserver 实现滚动时的 reveal 动画与技能进度动画
- 悬停反馈、按钮动效、移动端导航切换
- 响应式布局，兼容桌面与移动设备

如何使用：

1. 在浏览器中打开 `index.html` 即可预览。
2. 替换 `index.html` 中的个人信息与链接（姓名、头像、邮箱、项目链接等）。
3. 若需表单功能，请接入后端或使用第三方表单服务替换 `sendForm` 实现。

建议：

- 将个人项目的链接替换为真实仓库或演示地址。
- 可加入更多动画（如微交互、SVG 动画）或使用 AOS/GSAP 做更复杂的效果。
